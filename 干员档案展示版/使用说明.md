# 明日方舟干员档案展示版

当前首页搜索仅匹配干员名字、技能和天赋文字；台词、档案、职业与标签不参与搜索。

这是从本地中文服资料生成的离线网页档案和 Markdown 档案。中文化后的基础数据表已修正星级显示值。

## 阅读

- 双击打开 首页.html，按干员代号、职业、标签、技能、台词、档案或天赋中的关键词检索；多个关键词用空格隔开。阿米娅的三个形态分别列为独立档案。
- 每名干员的网页档案位于 干员档案/。
- 每名干员对应的 Markdown 档案位于 Markdown档案/。
- 仅有档案资料的人物单独列在 非干员档案/，Markdown 版本也在 Markdown档案/。

网页不加载外部图片、字体或脚本，也不需要联网或启动服务器。

## 展示规则

- 页面栏目和字段名按照玩家阅读习惯呈现；属性展示采用“生命上限”“攻击”“防御”“初始部署费用”等 PRTS 页面常见用语。
- 档案、个人记录、中文台词、技能和服装等描述保留中文服资料原文。
- 星级采用汇总档案中已按原始枚举修正的 1～6 星显示值；干员信息分别显示主要所属势力、其他所属势力和标签。
- 特性栏目显示各形态的职业分支、分支描述及额外特性；攻击范围按精英阶段绘制方格图，右侧代表干员朝向。
- 获得方式栏目显示国服上线时间、上线途径和主要获得方式；阿米娅的医疗与近卫档案分别显示对应形态的上线记录。
- 培养材料栏目展示精英化、技能升级和专精所需的中文物品名称与数量。
- 台词栏目仅展示文字，不含音频；多语种台词栏目保留英语、日语、韩语及繁体中文源文，原本为外语的台词不翻译。来源缺少某个语种时会明确标出，不补造台词。
- 中文服原文中的外文专名、角色名和品牌名按原样保留，不作转写或意译。
- 游戏数据中的富文本标签会移除；可由同一资料块参数表还原的数值占位符会展开。
- 原文中的动态昵称位置会标为“【博士昵称】”，便于离线阅读。
- 完整战斗属性收在每名干员页面“属性”栏目下的折叠区。

## 数据来源

主要展示内容来自 ../干员文字资料/全体干员文字资料.json，势力名称来自 ../干员文字资料/原始数据_中文服/阵营资料表.json。数据快照和提交信息见该目录内的 资料说明.md。

物品中文名称、职业分支名称、攻击范围和多语种语音取自 GitHub 仓库 [ArknightsAssets/ArknightsGamedata](https://github.com/ArknightsAssets/ArknightsGamedata) 的固定提交 `f6a8967a14aad645b025afdada5a88e1aaeb2762`，提取后的数据存放在 资料映射/。国服上线时间、上线途径和主要获得方式取自 PRTS 的单张[干员上线时间一览](https://prts.wiki/w/%E5%B9%B2%E5%91%98%E4%B8%8A%E7%BA%BF%E6%97%B6%E9%97%B4%E4%B8%80%E8%A7%88)，读取日期为 2026 年 9 月 24 日，没有逐个抓取 PRTS 干员页面。上线途径说明首次上线背景，主要获得方式是该汇总页的记录，并不表示所有途径此刻仍开放。

参考页面：[阿米娅](https://prts.wiki/w/Amiya)、[能天使](https://prts.wiki/w/Exusiai)、[凯尔希·思衡托](https://prts.wiki/w/%E5%87%AF%E5%B0%94%E5%B8%8C%C2%B7%E6%80%9D%E8%A1%A1%E6%89%98)。

## 重新生成

在此目录运行以下命令：

    python 生成展示档案.py

已有资料映射时，脚本仅依赖 Python 标准库和本地 JSON，无需联网。重新生成时会同步生成离线的 `检索索引.js`；搜索直接读取本地脚本，无需服务器。若需要重建 GitHub 资料映射，先运行 `python 准备展示映射.py` 从上述固定提交下载源表；也可用 `--原始目录` 指向已下载的 `item.json`、`range_table.json`、`uniequip_table.json` 与 `voice-en.json`、`voice-jp.json`、`voice-kr.json`、`voice-tw.json`。`上线与获得方式.json` 是从 PRTS 汇总页单独整理的本地映射，重建 GitHub 映射时不会覆盖它。
