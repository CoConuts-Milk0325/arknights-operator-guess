## 一、 修改背景与处理原则

基于对 PRTS Wiki《异常效果》《伤害分类》《伤判效果》《BUFF》《失衡位移机制》《选择器》《术语释义》《作战机制》等技术性文档的对标核查，并结合四大模型交叉互审结论及用户反馈，我们对干员展示档案生成器、离线线索生成器及其数据索引进行了系统性审查与修改。

本次修改遵循以下核心原则：
1. **阿米娅形态彻底解耦**：将阿米娅的三种形态（术师、近卫、医疗）在干员档案展示版与猜干员事实索引中彻底划分为三个独立的干员，各自分配专属模组、技能与台词，严禁数据穿透与跨形态污染；
2. **真实机制对齐与自相矛盾消除**：修复赫德雷真伤被标纯物理、响石漏法伤、黍漏传送、波登可漏沉默、具名引爆/弹药/充能词法漏判等机制缺陷；
3. **主体行为严格消歧**：严格剥离干员本体攻击与召唤物（Mon3tr、令召唤物）以及治疗跳跃（链愈师），避免给干员本体打上不属于自身的机制标签；
4. **保留元素伤害/损伤通用口径**：遵循用户指示，不将“元素伤害”与“元素损伤”强行拆分，保持既有机制分类的统一收录；
5. **规则闭环与死蕴含清零**：补全炮手对空，严格过滤 `implies`，消除所有指向不存在事实的空蕴含，出题时过滤 100% 全等线索；
6. **全量重算与回归验证**：刷新展示档案，重算 431 名干员 Fallback 保底题库，跑通 8620 局出题模拟与全套单元测试。

### 1. 🔴 [P0] 补全沉默控制词典，修复控制聚合事实（`CONTROL_NAMES`）

  CONTROL_NAMES = {

      "freeze": ("冻结",), "cold": ("寒冷",), "sleep": ("沉睡",),

- **修复效果**：

### 3. 🟡 [P1] 攻速增益正则剔除维持条款（排除信仰搅拌机）
- **涉及文件**：`猜干员网页游戏/生成游戏数据.py`
- **问题根因**：增益动词中包含 `不会低于`，导致信仰搅拌机模组中的底线维持条款“*使场上所有【拉特兰】干员的攻击速度不会低于战斗开始时的攻击速度*”被误判为主动的攻速增益。
- **具体修改**：
  在 `OUTPUT_BUFF["attack"]` 和 `OUTPUT_BUFF["speed"]` 的正则中彻底删除 `|不会低于` 分支：
  ```python
  r"攻击力(?:和防御力)?(?:\+|提高|提升|增加|上升|提升至)|..."
  r"(?:攻击速度|攻速)(?:\+|提高|提升|增加|上升)|..."
  ```
- **修复效果**：信仰搅拌机不再被错误计入 `ally:output:speed` 与 `ally:output_multi`。

### 4. 🟡 [P1] 持续生命回复（Regen）判定扩展与群体回血拐收录
- **涉及文件**：`猜干员网页游戏/生成游戏数据.py`
- **问题根因**：原 `own_regen` 仅匹配硬编码的汉字 `生命回复速度`，导致调香师、安洁莉娜、浊心斯卡蒂、黍、歌蕾蒂娅等大量使用“每秒回复/恢复生命”的标准 Regen 拐全军覆没，`heal:hunger` 沦为斑竹一人的私货事实。
- **具体修改**：
  重构 `own_regen` 判定函数，完整支持吟游者特性、各种光环与技能的群体持续回血，并严格排除自愈（如山、绮良）、纯召唤物回复（如深海色触手、缪尔赛思流形）以及损伤回复（如纯烬艾雅法拉）：
  ```python
  def own_regen(sources: list[tuple[str, str]]) -> tuple[str, str] | None:
      for label, phrase in sources:
          if "持续恢复范围内所有友军生命（每秒恢复" in phrase or "持续恢复范围内所有友方生命" in phrase:
              return label, compact(phrase)
          for clause in re.split(r"[；;。\n]", phrase):
              if re.search(r"(?:友方|我方|其他).{0,18}(?:干员|单位).{0,45}生命回复速度", clause):
                  return label, compact(phrase)
              m = re.search(r"(?:所有|全体|全场|全地图|周围|附近|范围内|攻击范围内|场上|地块上|播种地块|落点周围|【[^】]+】干员|友方|我方|其他干员|其他友方|其他角色)"
                            r"[^，,；;。]{0,25}"
                            r"(?:每秒(?:回复|恢复)|持续恢复|持续回复|获得每秒回复)(?!.{0,25}损伤).{0,30}(?:生命|最大生命)", clause)
              if not m:
                  m = re.search(r"(?:使|令|让)[^，,；;。]{0,25}(?:周围|友方|我方|其他|所有|全体|全场|范围内)[^，,；;。]{0,20}每秒(?:回复|恢复)(?!.{0,25}损伤).{0,30}(?:生命|最大生命)", clause)
              if not m:
                  m = re.search(r"每秒(?:为|向)(?:周围|范围内|所有|全体|全场|友方|其他|附近)[^，,；;。]{0,20}(?:回复|恢复)(?!.{0,25}损伤).{0,30}(?:生命|最大生命)", clause)
              if m:
                  matched_text = clause
                  if re.search(r"^(?:自身|自己)每秒", matched_text.strip()):
                      continue
                  if re.search(r"(?:自身|自己).{0,10}(?:防御力|攻击力|阻挡数).{0,30}每秒(?:回复|恢复)", matched_text):
                      continue
                  if re.search(r"所有触手|流形为", matched_text):
                      continue
                  return label, compact(phrase)
      return None
  ```
- **修复效果**：
  - 调香师、安洁莉娜、浊心斯卡蒂、空、海蒂、黍、歌蕾蒂娅、塞雷娅、瑕光、引星棘刺等 22 名群体回血拐全部被准确收录进 `heal:hunger`；
  - 纯烬艾雅法拉（回复元素损伤而非生命）未被误收。

## 五、 2026-09-27 第二轮迭代：控制识别纠偏、复合闪避、费用提取与线索消歧

### 1. 修改背景

在游戏实战对局中，用户反馈了以下 6 项核心机制逻辑断层与题面表述歧义：
1. **卡达题自相矛盾**：线索声称“没有任何控制效果”，证据却罗列出二技能拥有“27%概率晕眩敌人1秒”；
2. **减速（降低移动速度）脱靶**：游戏内大量使敌人移动速度降低的核心控制技能未被算作行动限制，导致阿斯卡纶、极境、白雪、夜魔等 14 名核心控制干员被贴上“未发现对敌方移动或行动的限制”的荒谬标签；
3. **缪尔赛思回费漏收**：伺夜题目线索同时吻合缪尔赛思，但缪尔赛思因官方文本“立即获得15点费用”和“期间逐渐回复”未带“部署”二字而未被收录；
4. **娜仁图亚复合闪避漏收**：娜仁图亚天赋“物理与法术闪避”因中间存在连词，导致物理闪避事实漏判；
5. **蓝毒天赋法伤丢失**：蓝毒因天赋“神经毒素”在逗号后叙述法术伤害，被误判为“只能造成物理伤害”；
6. **阻挡与初始技力题面歧义**：高台干员在官方属性中基础阻挡为 1 引起困惑；傀影全被动技能与“初始技力为0”产生理解歧义。

### 2. 详细修改清单

#### 8. 🔴 [P0] 修复控制识别中的自身动作主体过滤边界与状态结束判断

### 2. 元素脆弱漏收的复盘与分型结果
