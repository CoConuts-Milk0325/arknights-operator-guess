# 密封档案 · 猜干员｜完整规则

本规则适用于本仓库当前的“线索猜干员”游戏。页面上的线索以当前事实索引和干员资料快照为准；以下说明解释玩家如何作答，以及一条线索在什么条件下成立。

## 一、目标与一局流程

每局系统选定一名目标干员，并组合四条线索。开始时只公开第 1 条。你可以根据已公开的线索猜测，也可以直接查看下一条。

页面上方可多选 **1～6 星**，所选星级同时限定随机答案和搜索框中的作答候选，至少须保留一个星级。首次打开默认全选；之后会在本浏览器记住选择。
游戏中的修改选会立即生效：如果当前答案仍在新范围内，本局进度保留；如果被排除，系统重新抽题，并清空本局猜测和线索进度。被重开的旧题不计入已完成局数或总分。结算后改选则从下一题开始生效。

1. 在搜索框输入名字、外号或拼音（支持全拼与首字母），**从候选列表中选中干员**，再点击“确认猜测”。共用外号会显示多个候选；完整本名优先。只输入文字而没有选中候选，无法提交。
2. 第 1～3 条线索阶段，每猜错一次会自动公开下一条；主动点击“查看下一条线索”也会公开下一条。
3. 第 4 条公开后，猜错不会结束本局，也不会出现第 5 条；可继续猜，直到猜中或主动放弃。同一名干员不能在本局重复提交。
4. 猜中或点击“放弃本题”后，才揭晓目标和四条线索各自的依据。此时本局结束，点击“下一题”开始新局。

第 1、2、3、4 条线索阶段猜中，分别得到 **4、3、2、1 分**；放弃得 0 分。得分只由**猜中时已公开的线索数**决定，不按猜错次数另外扣分。四条线索全公开后，即使多次猜错，最终猜中仍得 1 分。(其实分数没什么用，也没有排行榜，甚至连算总分的功能都没有)

四条线索的交集在**本游戏当前候选与事实索引**中只有一个答案；前一、二、三条不保证已经唯一。不同局可能出现相同干员或相近线索，游戏没有保证永不重复的题库。
星级筛选只缩小出题和作答范围，不放宽四条线索在完整候选库中唯一的要求。

## 二、答案范围与资料版本

当前版本包含 **431 名候选干员、441 条线索事实**，431 名干员都有可生成的四线索题。阿米娅、阿米娅（医疗）、阿米娅（近卫）是三个不同答案；其他异格、形态或名称相近的条目也以候选列表中的**完整名称**分别作答。未列在本游戏候选列表中的角色不能作为答案。

干员资料均以**2026-09-04结城理版版本**为准。资料更新后，候选数、事实数和个别题面可能变化。结算页会显示目标的星级、职业和档案链接，供玩家核对。

## 三、一条能力线索怎样算成立

### 1. 默认养成与合法配置

- 满练：默认采用该干员**能达到的最高精英阶段、最高等级、各技能的最高合法等级**，通常包括专精三；低星干员按自己的实际等级和技能上限。默认按**零潜能**判断。
- 满潜：题面明确写“**满潜满练**”时，该条费用线索才使用满潜满练数值（包含最高精英阶段基础费用、潜能减费及可能的常规模组减费）。
- 所有“**特限证章**”及其效果均不参与盘点。盘点能力时，包括普通攻击、特性、天赋、全部可携带技能，以及常规模组。模组按其最高等级效果判断。

### 2. “有”“没有”“同一技能”的范围

- “**有技能能……**”“**可以……**”通常表示：在至少一种合法配置、条件或时机下，干员能实现该效果；不要求整场常驻，也不要求不开技能时就能做到。
- 条件性和概率触发的能力也属于“可以”，证据须说明条件。例如丰川祥子二技能在 **Fever 期间**变为二连击，薇薇安娜二技能有概率变为二连击，两者都具备“有技能可连续进行两次攻击”的能力。
- “**没有……**”“**无……能力**”“**仅能／只能……**”是对**全部合法能力和配置**的排查。
- “**有技能既能 A，也能 B**”“**同一技能……**”“**有技能兼具……**”要求**同一个技能及一套合法模组配置**具备两项能力。两项效果可按技能条件作用于不同目标或不同时机；题面若没有写“同一目标”“同一击”，就不额外要求同一目标同时承受两项效果。
- 题面明确说“**不同技能分别……**”“**不止一个技能……**”时，才按字面比较多个技能。**不同的线索**也可以由目标干员的不同技能、模组或合法配置分别证明；不要求整题四条线索在一场战斗中同时实现。
- “**可造成两种伤害类型与一种控制效果**”以及单独的伤害／控制种类计数，按该干员**全部合法能力的并集**统计；它不是要求某一个技能同时具备整套种类。相反，写明“有技能既能造成甲伤害，也能造成乙伤害”时仍须检查同一技能。

### 3. 主体、对象和触发条件

“**自身**”指答案干员本体；“**其他干员**”不包括本体。自己的召唤物、替身、装置等在能对敌攻击、施加控制、治疗或支援时，可计入该干员提供的战斗能力；但它们自己的生命变化、护盾、回血、阻挡数或属性提升，不能冒充干员**本体**的“自身”效果。只给自己或召唤物的增益，也不能冒充“给其他干员”的支援。

“部署后”“首次阻挡”“受击时”“生命值较低时”“技能期间”“有友方阻挡敌人时”等都是能力的成立条件。满足条件才算；不把一次条件性效果说成无条件常驻。题面若指“普攻”“技能”“天赋”“特性”，还须由对应来源证明，不能用另一来源替代。（比如天赋提供的闪避不能算是技能提供的）

## 四、常见机制词的判定

| 题面用词 | 在本游戏中的意思与边界 |
| --- | --- |
| **普通攻击可以对空** | 普攻在正常状态下能**主动选取飞行目标**。仅能打到自己已经阻挡的飞行单位不算。技能、召唤物或受击反伤能打飞行目标，也不能据此说“普攻可以对空”。（比如维什戴尔三技能、星熊二技能） |
| **无对空攻击能力** | 检查干员全部能造成伤害的手段，包括普攻、技能、天赋、合法模组、召唤物、替身及受击反伤。只要其中一种能伤害飞行目标，就不满足“无对空”；它与“普攻可以对空”**不是互补的两类**。 |
| **伤害类型** | 线索统计物理、法术、真实、元素四类。弱点伤害按可能转化出的物理／法术类型统计，不另算第五类。治疗不是对敌伤害（但是在prts里确实属于第五种伤害）。 |
| **弱点伤害** | 弱点伤害不是独立的第五类伤害。它会按目标的防御力、法术抗性或固定弱点转为物理或法术伤害；本游戏统计干员的可能伤害类型时，两种可能都计入。 |
| **元素伤害／元素损伤** | **本游戏的线索口径**把对敌施加元素损伤计入“可以造成元素伤害”和伤害种类统计；凋亡、灼燃、神经、侵蚀等损伤另有各自线索。元素损伤本身不等于立刻扣除生命值。回复友方元素损伤、降低友方受到的元素损伤，不是对敌造成元素伤害。 |
| **持续伤害** | 敌人在一段时间内按周期或持续效果反复受伤。连续斩击、追击、延时一次爆炸、己方屏障衰减等不能算持续伤害。 |
| **异常状态与位移** | 统计能**对敌施加**的不同名称的异常状态或位移效果，如停顿、束缚、晕眩、沉睡、寒冷、冻结、浮空、恐惧、沉默、战栗、推开、拉拽、传送等。寒冷与冻结分别计；同一种效果施加多次仍只计一种。。 |
| **减速与停顿** | 只写“敌人移动速度降低／-N%”的是**移动速度削弱**，不作为一种有名称的异常状态或位移效果，也不增加“可造成 N 种类型的异常状态或位移效果”的计数；它单独对应“可以降低敌人的移动速度”。明确施加“停顿”时，停顿是异常状态。两者都会让敌人走得更慢，但题面按效果机制区分，不能互换。 |
| **真群攻** | 一次有伤害的攻击或技能作用于明确的空间范围内**所有敌人**，没有固定目标人数上限（aoe）。“攻击自己阻挡的所有敌人”或“友方阻挡的所有敌人”受阻挡关系限定，不算真群攻。只施加状态而不造成伤害，也不算真群攻。 |
| **最多 N 名敌人** | 在技能最高等级下，**同一次实际伤害动作**最多能伤害题面指定的 N 名敌人；锁定后真正攻击的额外目标计入总数。只锁定、只施加状态、停止攻击，或攻击区域内全部敌人而无固定人数上限，均不能混同这类精确人数线索。 |
| **连续 N 次攻击** | 一个技能描述中的连续攻击或连发次数，包括条件或概率触发的连击；成立条件保留在依据中。不能把“同时攻击 N 个目标”当成“连续攻击 N 次”。弹射、跳跃传导、溅射、穿透与固定多目标也是不同的作用方式，不能算在这类词条下。 |
| **直接治疗／生命回复（缓回）** | 直接治疗是一次治疗行为（就是跳绿字的治疗）；缓回是生命回复效果（就是不跳绿字的治疗）。回复元素损伤也不等于回复生命。 |
| **护盾、屏障、庇护、闪避、抵抗、免疫、无敌** | 各按题面所写效果判定。“抵抗”指缩短异常状态持续时间；“免疫”是不受相应效果；“庇护”是受伤害降低。友方生存增益不含直接治疗。 |
| **脆弱与专属脆弱** | 脆弱可对应物理、法术、真实伤害增幅；物理、法术、元素专属脆弱按各自类型判断。三种脆弱互不相同，降低敌方防御／法抗、提高敌方所受伤害、降低敌方攻击力等也不属于脆弱。 |
| **物理脆弱／物理增伤** | “能使敌人获得物理脆弱”仅收录资料明确写出的物理脆弱效果。“可使敌人受到的物理伤害增加”范围更广，包含物理脆弱、普通脆弱及其他物理受伤增幅；这两条不会同时出现在同一道题中。 |
| **通常不进行普通攻击** | “通常”指常态；某些干员在技能开启等条件下仍可能攻击。因此这条与“某技能期间能攻击／对空”并不必然矛盾。 |

## 五、其他线索怎样读

- **索敌**：优先攻击、仅攻击、随机选择目标分别按字面意思理解；优先攻击飞行、被阻挡、未被阻挡、高防御力、精英或领袖敌人不能互换。
- **攻击与范围**：普通攻击、技能攻击、受击反击要分开；攻击范围扩大、缩小、变为全战场或能打到原范围外，是不同条件。
- **范围形态变化**：网格判定的“扩大”要求有新增格且没有丢失格（真超集）；“缩小”要求丢失格且没有新增格（真子集），还须确认变化的是本体范围。明示“扩大／缩小／缩短”的本体技能或天赋文字可作为补充证据。同时新增前方格、丢失侧方格的技能属于形态改变，不仅凭格数增减判为扩大或缩小；召唤物的爆炸、装置支援范围等于本体范围。（浊蒂的也不算）
- **阻挡**：“不开技能时通常阻挡 N 名”看满潜满练条件下的常态本体阻挡数（铁卫的y模不算）；“技能改变自身阻挡数”必须变化在本体，友方或召唤物的阻挡变化不算。
- **技力与技能**：自动／手动／被动是触发方式；自动／攻击／受击回复是技力回复方式，两组词不可混为一谈。题面写“同一技能自动触发且攻击回复”时，两项必须在该技能上成立；“不同技能分别……”则比较两个技能。充能次数、初始技力、技能消耗、弹药量、持续时间均按题面及最高技能等级（专三）的具体数值读。
- **友方支援**：给其他干员的攻击、攻速、弹药、技力、防御、法抗、闪避、护盾、庇护、阻挡等按**实际受益对象**判断；“多名其他干员”须能覆盖多名，不把只作用于自己或一个召唤物的效果算进去。
- **部署与召唤**：击杀回费、技能直接回费、持续回费、撤退返费、降低费用是不同机制；“拥有召唤物”“获得陷阱”“释放浮游单元”也按题面的具体对象区分。
- **技能直接回费**：技能能一次性结算一定部署费用，金额可固定或随机，也可以等到技能结束才到账。每次攻击、每个命中目标或按时间周期累计回费不作为这条线索的依据；“下次攻击”一次性结算费用可以计入。拥有多种回费技能时分别判断，只要其中一个符合即可。
- **星级、职业、分支及数字**：分支“覆盖 N 个星级”是统计**当前 431 名候选中**该分支出现过几个不同星级。“满潜满练部署费用”依题面明确采用满潜满练；可能的常规模组减费也要按线索的具体证据核对。精确弹药量、持续秒数、技力消耗取最高合法技能等级（专三）。每题的统计／精确数值类线索**合计最多一条**。

## 六、出题、记录与核对

四条线索由当前事实索引重新组合，而非固定手写题单。同题尽量覆盖不同机制类别；同主题或一条已包含另一条含义的线索不会成对使用，同题最多一条复合线索。系统在出题时检查四条线索的候选交集，必要时使用已备好的唯一解组合。

页面底部的“已完成局数／总分”在**猜中或放弃并结算**时更新。浏览器会保存最近出过的答案、线索和题目组合，优先减少近期重复；它在开启一局时就记录该题已出现，所以中途关闭页面或因改选星级重抽，也可能影响近期避重。仅选择少量干员时，全部轮过后仍可再次抽到之前的答案。记录不可用时仍可游玩。点击“清除记录”会清除本浏览器保存的局数、总分和近期避重记录；**不会结束或重置正在进行的这一局，也不会清除星级选择**。

如果某条线索看起来不成立，先在结算页查看该条的依据，并打开目标干员档案核对技能等级、天赋、特性、模组、对象和触发条件。对于资料与 PRTS 机制说明的明确冲突，应逐项复核并修正事实索引；生成器仍有文本提取规则，索引唯一性本身不等于每条机制事实都已获人工逐项验证。旧页面若仍显示已修正的题目，刷新页面以加载新版索引。

## 七、常见疑问速查

**为什么我输入了正确名字却不能提交？** 必须在搜索建议中选中候选；自由输入的文字本身不提交。

**Fever 算技能吗？为什么 Fever 期间的二连击仍计入线索？** Fever 是 Ave Mujica 的共享机制，不是干员可携带的技能，激活 Fever 不能称为开启技能。但是丰川祥子的二技能明确写有“Fever 期间变为当前音色的二连击”：二连击属于该技能在特定条件下的效果，Fever 是成立条件。“有技能可连续进行两次攻击”允许在合法条件下成立，依据会注明 Fever 条件。

**召唤物能打飞机，干员算有对空吗？** 算干员具备某种对空伤害能力；但不能因此说干员的**普通攻击**可以主动对空。

**什么是异常状态与位移效果？** 本游戏的“异常状态与位移”指干员能对敌施加的有明确名称的状态或位移效果，包括受抵抗影响的 10 种异常状态（晕眩、寒冷、冻结、束缚、停顿、沉睡、沉默、浮空、恐惧、战栗）以及 3 种物理位移（推开、拉拽、传送）。同一种效果重复施加只算一种。

**弱点伤害算什么伤害？** 它不是第五种伤害类型。弱点伤害可根据目标属性或固定弱点转为物理或法术伤害，因此本游戏在统计干员可造成的伤害类型时，把这两种可能都计入。

**减速算不算异常状态或位移？为什么？** 如果“减速”只指敌人移动速度数值降低，它**不计入本游戏的异常状态与位移种类**；它统计的是明确施加的状态或位移效果。若文字明确写“停顿”，则按停顿这一异常状态计算。

**减速不算异常状态算什么？** 它算对敌人的**移动速度削弱**，对应线索“可以降低敌人的移动速度”。因此一名干员可以同时满足“无法造成异常状态或位移效果”和“可以降低敌人的移动速度”。

**为什么一个施加元素损伤的干员被算作可造成元素伤害？** 这是本游戏已确定的线索分类口径；它不表示施加损伤的瞬间已经扣除了敌人的生命值。
