# 2026-09-30 代码审查问题修复记录

本次修复此前代码审查确认的五项问题；仅修改应用逻辑、回归测试和文档，未修改语音数据、数据版本号或部署配置。

## 行为变化

| 问题 | 修复后的行为 | 主要文件 |
|---|---|---|
| 浏览器禁止访问 localStorage 时缓存清理再次抛错，导致成功下载的语音被丢弃 | 缓存清理和清空失败时安全退出，语音下载与出题继续工作 | `src/cache.js` |
| 旧语音或非活动播放器延迟报错会跳过当前片段 | 播放器只在活动时发送跳过事件；父组件按片段索引校验，并忽略加载中和已结束题目的事件 | `AudioPlayer.vue`、`GameBoard.vue` |
| 主备源均失败后，网络/解码错误被忽略，界面仍显示播放中 | 主源失败最多回退一次；备用源再发生错误码 2、3、4 时停止播放、清理定时器和状态，每次加载最多通知跳过一次 | `AudioPlayer.vue` |
| 挑战中改变最大猜测次数，当前选项数没有同步 | 当前选项随输入模式及上限重新生成，正确答案保持在选项中；若已猜次数达到新上限，立即按失败结算一次 | `GameBoard.vue` |
| 基础语音类型全选仍排除皮肤条目 | 选择“登录”等基础类型时，同时包含“登录（皮肤）”等对应条目，显示时保留原始类型 | `src/logic/gameEngine.js` |

音频卡片新增“重试语音”按钮：重建当前音频实例，从主源开始重试并播放，仍允许一次备用源回退。最后一条语音失败时保留当前题，可直接重试；重试不会消耗新的干员或猜测次数。

降低猜测上限触发失败结算时，记录最后一次猜测，不添加虚构猜测，也不推进到额外语音。成功/失败统一使用有重复调用保护的结算函数。

## 验证

新增 8 项回归测试，先在旧实现上观察失败，再修改生产代码使其通过：

1. 禁用浏览器存储后，成功下载的题目仍可使用。
2. 旧片段、重复事件及已结束题目的错误不会跳过当前语音。
3. 非活动播放器主备源都失败时不发送跳过事件。
4. 备用源终止错误（2/3/4）清理播放状态与进度定时器，仅通知一次跳过。
5. 当前失败语音可重新从主源加载并播放。
6. 挑战中调整上限同步选项数，不占用另一名干员。
7. 已达到降低后的上限时只记录一次失败。
8. 基础类型筛选包含对应皮肤条目，同时排除其他类型。

验证命令：`npm test`、`npm run verify:data`、`npm run build`。

- 仓库交接文档及工作区根目录 `HANDOVER.md` 已同步更新相关规则和记录入口。
